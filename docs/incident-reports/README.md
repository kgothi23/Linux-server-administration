# Incident reports

Use this directory to document practical troubleshooting exercises.

Each report should include:

1. **Summary:** What failed or behaved unexpectedly?
2. **Impact:** What was unavailable or affected?
3. **Symptoms:** What did you observe?
4. **Investigation:** Which commands, logs, and checks did you use?
5. **Root cause:** What caused the issue?
6. **Resolution:** What change fixed it?
7. **Verification:** How did you confirm recovery?
8. **Lessons learned:** What would you monitor or improve?

Only mark a report as resolved after verification. Do not include secrets or sensitive host information.
